Privacy Policy

Effective 10 September 2026. Applies to the Mubaddil Windows app and this website.

This program will not transfer any information to other networked systems unless specifically requested by the user or the person installing or operating it.

The Windows app

Mubaddil runs only on your PC. It is offline. It has no account, no cloud, and no analytics.

  • It does not log what you type.
  • It does not save your messages.
  • It does not send data to the internet.
  • It does not need administrator rights.

It only looks at the first one or two words in a field so it can fix a wrong Arabic/English keyboard layout, then it stops. That work stays on your machine.

This website

The site at bdil-chi.vercel.app is a public download page. We do not ask you to create an account. We do not run ads. We do not use a marketing tracker.

The site is hosted on Vercel. Like most hosts, Vercel may keep ordinary server logs (for example the time of a visit or a download) to run and protect the site. We do not use those logs to profile you.

Source code is on GitHub: github.com/AnasKhaled1876/mubaddil.
